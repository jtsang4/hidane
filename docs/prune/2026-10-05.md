## Architecture

### A1 — acceptance keeps only what needs a real model, CLI, OS or judgement

- Outcome: partially landed (4 of the identified scenarios); the rest deferred by scenario
- Problem: a read-only survey mapped every expectation in `acceptance/scenarios.md` to the tests. About 40 deterministic expectations (status codes, events, validation) had no test and were verified by the LLM tester on every run; 4A and 6D were entirely covered already. Some waits were literal: 4H waited 40 s for an interval, 4E 20 s of idle for a ping. The `--changed` map also under-selects: 4G is reachable from no path, and `internal/api` omits 4F, 4I, 4R, 5C.
- Target rule: deterministic expectations live in Go/Playwright tests; `scenarios.md` keeps only model/CLI/OS behavior and semantic judgement — check: each deleted bullet has an asserting test (listed in the commit messages)
- Commits: d34d2b1 (4H, 4L), 8ad6655 (4E, 4N); review fixes 4aefb85, d624206
- Payoff, expected vs. actual: four scenarios with ~70 s of fixed waits gone from the tester's run; replaced by tests that take < 0.5 s
- Enforcement added: none (the rule is an instruction, see Feedback)
- Notes: per-scenario migration keeps each step complete. Next candidates, by tester time: 4J (files, traversal variants, binary/too-large, download), 4K, 4F, 4O/4P API parts, 4Q endpoint, 5C route endpoint, 5D escalation via the fake's NEEDS_INPUT, 5I down to a screenshot judgement (declined this run as S3; revisit only with the user).

## Feedback

- Recurring smells: deterministic checks written into acceptance scenarios instead of tests (about 40 expectations across 4B–5H, 6A, 6C, 6E); fake-CLI delays applied to more turns than a test needs.
- Proposed instruction rule (AGENTS.md, Verification): "An expectation a test can assert — a status code, an event row, a file, a validation error — goes into a Go or Playwright test, not into `acceptance/scenarios.md`; scenarios describe only what needs a real model, a real CLI, the OS, or judgement." — status: pending (user approval)
