## Architecture

### A1 — acceptance keeps only what needs a real model, CLI, OS or judgement (continued)

- Outcome: landed (all six approved scenarios, plus covered bullets across the rest via S8)
- Problem: after the first run, 4J/4O/4P/4Q/5A/3 and about 60 bullets elsewhere were deterministic expectations a model re-verified every run
- Target rule: every deleted bullet names the test that asserts it (commit bodies); each new test was checked to fail when its behavior is broken
- Commits: 905f77f, then 450a560 (S8)
- Payoff, expected vs. actual: expected ~25 tester minutes per full run for six scenarios; actual 8 scenarios gone (3, 4J, 4O, 4P, 4Q, 5A, 5E, 5H) and 242 scenario lines, an estimated 40+ minutes of a full run
- Enforcement added: the rule already in AGENTS.md (Verification)
- Notes: scenarios 4C, 4R, 5C, 7B and 7C hold nothing a fake can assert

- Commits: d1585ef
- Payoff, expected vs. actual: Go 6 → 1, TS 4 → 1, as expected; lines +45 (the test). - Outcome: reverted
